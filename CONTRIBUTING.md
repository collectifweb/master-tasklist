# Contribution

## Installation locale

1. Cloner le dépôt.
2. Copier `tasks.example.json` vers `tasks.json`.
3. Démarrer un serveur HTTP statique.
4. Ouvrir l’application ou le prototype 006 dans le navigateur.

## Avant un commit

- Valider les modules JavaScript avec `node --check`.
- Valider les fichiers JSON.
- Tester au minimum les largeurs 390 px, 834 px et 1280 px.
- Vérifier que l’ajout et la modification de tâches fonctionnent.
- Vérifier le placement d’une construction.
- Confirmer qu’aucune tâche réelle, capture privée ou information d’accès n’est suivie par Git.

## Données de démonstration

Utiliser uniquement des tâches fictives et génériques. `tasks.json` ne doit jamais être ajouté au dépôt.

## Commits

Utiliser des messages courts et explicites, par exemple :

```text
feat: add farm construction flow
fix: keep entity labels above the map
 docs: explain hosted data separation
```
